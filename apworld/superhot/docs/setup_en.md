# SUPERHOT Setup Guide

*This world isn't playable yet -- this file is a placeholder for the real setup guide
that Archipelago's webhost expects to find, so `WebWorld.tutorials` has something valid
to point at.*

## Planned steps (once the mod exists)

1. Install [MelonLoader](https://melonloader.co) into your SUPERHOT installation.
2. Drop `SuperhotArchipelago.dll` (built from `mod/SuperhotArchipelago/`) into your
   `Mods` folder.
3. Install the `.apworld` file into your Archipelago install via the launcher's
   "Install APWorld" button.
4. Generate or join a multiworld game as usual.
5. Launch SUPERHOT; use the in-game console/menu the mod adds to connect to your
   room (server address, slot name, password).

None of steps 1-2 are buildable yet -- see the project root `NOTES.md`.
